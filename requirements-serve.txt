# Serving subset of requirements.txt — what the API actually imports.
#
# requirements.txt remains the full set (ingestion, evaluation, tests) and is
# what you install for local development. This file is ONLY for the runtime
# container image, and every version here is pinned to match requirements.txt
# exactly. If you bump a version there, bump it here too — a silent drift
# between the two would mean the image runs different code than the tests.
#
# What is deliberately absent, and why it is safe:
#
#   pymupdf, pdfplumber   PDF parsing — imported only by
#                         app/services/ingestion/{text,table}_extraction.py and
#                         validation.py, which the serving path never imports.
#   scikit-learn          Not imported by app/, but NOT actually saved: it is a
#                         hard install_requires of sentence-transformers 5.7.0,
#                         so pip installs it (and scipy, joblib, threadpoolctl)
#                         transitively anyway. Listing it here would be
#                         redundant, not smaller. Removing it for real would
#                         mean vendoring the handful of ST code paths that
#                         import it — not worth it for ~160 MB.
#   aiosqlite             DATABASE_URL/traces.db is declared in .env.example but
#                         is not read by any code in this repo.
#   structlog             Superseded by app/observability/logging.py, which uses
#                         the stdlib logging module directly.
#   pytest, pytest-asyncio  Test-only.
#
# This was verified empirically rather than by reading imports: importing
# `app.main` and inspecting sys.modules shows none of the above are loaded.
# `app/services/ingestion/__init__.py` is empty, and tokenization.py — the one
# ingestion module the serving path does import (via embedding_provider) —
# imports only `re` and `typing`.
#
# Re-check with:
#   PYTHONPATH=backend python -c "import sys, app.main; \
#     print([m for m in ('pymupdf','fitz','pdfplumber','sklearn','scipy', \
#     'structlog','aiosqlite','pytest') if m in sys.modules])"
# An empty list means this file is still correct.
